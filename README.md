# Gender Classification CNN (Male/Female)

A deep learning project using TensorFlow CNN to classify faces as male or female.

### Model Details
- Input size: 150x150 RGB
- Architecture: 3 Conv layers + Dense layers + Dropout
- Binary crossentropy + Adam Optimizer
- Early Stopping used to prevent overfitting

### Streamlit App
Upload an image and get instant classification.

### Install Requirements
pip install -r requirements.txt

### Run the App
streamlit run app.py

### Dataset 
URL - https://www.kaggle.com/datasets/ashwingupta3012/male-and-female-faces-dataset

### Model
URL - https://huggingface.co/Peacfl/Gender-Classification-CNN-Male-Female/
